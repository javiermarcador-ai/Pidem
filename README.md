# Pidem

**Pidem** es una aplicación Android para la captura, organización y consulta de fotografías y documentos, incorporando extracción automática de texto mediante OCR.

La aplicación está pensada para poder fotografiar documentos, obtener el texto que contienen y mantenerlos organizados mediante categorías, notas y búsquedas.

---

## Pidem v1.0.0

Primera versión estable de Pidem.

### Características

- Captura de fotografías desde la cámara.
- Importación de imágenes desde la galería.
- Extracción de texto mediante OCR.
- Gestión de documentos y fotografías.
- Fotografías principales y fotografías adjuntas.
- Notas asociadas a los documentos.
- Organización mediante categorías.
- Búsqueda de documentos.
- Exportación de datos.
- Importación de datos mediante archivos de extensión `.eiP`.
- Gestión de categorías.
- Eliminación completa de datos e imágenes.
- Manual de usuario integrado en la aplicación.

## Primer inicio

Al ejecutar Pidem por primera vez, la aplicación solicitará al usuario que seleccione una carpeta para almacenar las imágenes de Pidem.

### Selección de la carpeta

1. Pulsa **«Seleccionar carpeta»**.
2. Elige la carpeta donde deseas almacenar las imágenes de Pidem.
3. Pulsa **«Usar esta carpeta»**.
4. Concede a Pidem el permiso solicitado por Android.

Una vez concedido el permiso, Pidem estará listo para utilizarse.

### Importante

La carpeta seleccionada será utilizada por Pidem para almacenar las fotografías principales y las fotografías adjuntas de los documentos.

La ubicación de esta carpeta es elegida por el usuario durante el primer inicio.

El desarrollador **recomienda instalar** la aplicación en el lugar que se propone por defecto, siendo solamente necesario otorgar permiso a la **carpeta inicial**.

## Captura y organización de documentos

Pidem permite realizar fotografías utilizando la cámara del dispositivo y obtener automáticamente el texto legible mediante OCR.

Cada documento puede contener:

- Fotografía principal.
- Segunda fotografía.
- Fotografías adjuntas.
- Texto obtenido mediante OCR.
- Notas.
- Categoría.

Los documentos pueden consultarse posteriormente mediante la lista de documentos y utilizar el buscador para localizar información.

---

## Categorías

Los documentos pueden organizarse mediante categorías.

Pidem incluye una categoría denominada:

**Documentos**

Esta categoría existe siempre y no puede eliminarse.

Las demás categorías pueden ser creadas, modificadas o eliminadas desde la aplicación.

La categoría **«Todas»** funciona únicamente como filtro de visualización y no puede asignarse a un documento.

---

## Importación y exportación

Pidem permite realizar copias de los datos mediante archivos con extensión:

`.eiP`

Estos archivos pueden utilizarse para trasladar información entre instalaciones de Pidem.

La importación incluye:

- Fotografías principales.
- Segundas fotografías.
- Fotografías adjuntas.
- Texto OCR.
- Notas.
- Categorías cuando estas existen previamente en la instalación receptora.

Si un documento importado pertenece a una categoría que no existe en la instalación receptora, el documento será asignado automáticamente a la categoría **«Documentos»**.

La importación no crea automáticamente nuevas categorías.

---

## Eliminación de datos

Pidem permite eliminar documentos y sus imágenes asociadas.

También dispone de una opción para realizar una eliminación completa de los datos de la aplicación.

Cuando se eliminan documentos, Pidem elimina también las imágenes físicas asociadas que se encuentren almacenadas en la carpeta seleccionada para la aplicación.

---

## Manual de usuario

Pidem incorpora un manual de usuario integrado en la propia aplicación.

Para abrirlo:

1. Accede a la pantalla principal.
2. Pulsa el icono de información de Pidem.
3. Pulsa **«Ver Manual del usuario»**.

El manual se encuentra integrado como recurso de la aplicación y puede consultarse sin necesidad de conexión a Internet.
